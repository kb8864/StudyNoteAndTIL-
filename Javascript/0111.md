# アロー関数
- 無名関数なら関数名が入らない
```
function 引数）{
  処理
return 戻り値
};
```
そしてここからさらにfunctionも消せるらしい
```
(引数) => {
  処理
  return 戻り値
};
```
---
## QA
以下の関数をアロー関数に書き換え
```
 function add(a, b) {
    return a + b;
    }
```
 次のアロー関数の出力を答えて
```
 const greet = name => `Hello, ${name}!`;

console.log(greet("Alice")); -> Hello, Alice!
```
