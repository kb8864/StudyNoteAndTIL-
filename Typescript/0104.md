## watchモードについて

## 1tsconfig.json ファイルを準備 
tsc --init コマンドを実行して、tsconfig.json ファイルを生成
outDir, rootDir, include, exclude を編集
outDir : コンパイルされた Javascript ソースコードが出力されるフォルダ
rootDir : TypeScript ソースコードを配置するフォルダ
include : コンパイルする TypeScript ソースコードに含めるファイルやフォルダ
exclude : コンパイルする TypeScript ソースコードに含めないファイルやフォルダ


```tsconfig.json ファイル
{
  "compilerOptions": {
      ...
    "outDir": "./dist/",                      
    "rootDir": "./src/",                       
  },"include": [
    "src/**/*.ts"
  ],
  "exclude": [
    "node_modules",
    "**/*.spec.ts"
  ]
}
```


## 2package.json で npm スクリプトに登録
npm run watch で TypeScript を自動的にコンパイルするように設定

```package.json
{
  "scripts": {
    "watch": "tsc -w"
  },
  "devDependencies": {
    "@types/node": "^22.10.4"
  }
}

```

## 変数のスコープについて
変数の宣言は宣言した場所の中でしか使えない。
ダメな例

```
let add_tax = (price:number): number =>{
    const tax: number = 1.1;
    return Math.floor(price * tax)
}

console.log(tax);
console.log(add_tax(100));
```
```
console.log(tax);

            ^ReferenceError: tax is not defined

```

良い例
```

const tax: number = 1.1
let add_tax = (price:number): number =>{
    const tax: number = 1.1;
    return Math.floor(price * tax)
}

console.log(tax);
console.log(add_tax(100));
```

## オーバーロード関数について
異なる引数や戻り値のパターンがいくつかある関数をオーバーロード関数と呼ぶ。
１つの関数に複数のパラメータを使えるようなイメージ。
注意点として、TypeScriptでは、オーバーロード関数は、関数シグネチャ部分と実装部分の2つの部分に分けて書く。

https://typescriptbook.jp/reference/functions/overload-functions#%E3%82%AA%E3%83%BC%E3%83%90%E3%83%BC%E3%83%AD%E3%83%BC%E3%83%89%E9%96%A2%E6%95%B0%E3%81%AE%E6%96%87%E6%B3%95

https://jp-seemore.com/web/13143/#toc5

## ①文字列と配列を１つの関数で処理を行うオーバーロード

```
// 関数シグネチャ部分

function print_name(name: string): void;
function print_name(name: string[]): void;

//実装部分
function print_name(name: string | string[]): void{
    if(typeof name === 'string'){
        console.log(name + 'さん')
    }else {
        for (let n of name){
            console.log(n + 'さん')
        }
    }

}

print_name('田中');
print_name(['佐藤', '小林', '高山']);
```
```出力結果
田中さん
佐藤さん
小林さん
高山さん
```
引数の型に応じて、適切な関数が呼び出される。
引数が文字列の場合、そのまま表示する
引数が文字列以外の場合、配列の値が１つずつ渡されて表示する。

# TypeScriptのジェネリック型

https://jp-seemore.com/web/13665/

https://typescriptbook.jp/reference/generics#%E3%82%B8%E3%82%A7%E3%83%8D%E3%83%AA%E3%82%AF%E3%82%B9%E3%81%8C%E8%A7%A3%E6%B1%BA%E3%81%99%E3%82%8B%E5%95%8F%E9%A1%8C

- 関数定義時にどんな方がくるのか定まっていない時に使う。関数を呼び出す時に型を定めるイメージ。
- 関数を呼び出して型を決める時、戻り値の型も指定する必要があるので注意。
- ジェネリック型を学ぶことで関数を再利用して使うことが可能になるので、コードの冗長性を解消できる。


```TypeScript
function getRandomChar<Type>(...chars: Type[]): Type{
    const index:  number = Math.floor(Math.random() * chars.length)
    return chars[index];
}


console.log(getRandomChar<string>('a', '1', 'あああ'));
console.log(getRandomChar<number>(1, 2, 3));
```
