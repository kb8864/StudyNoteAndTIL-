# Static

static修飾子が付いているメソッドを「クラスメソッド」、
フィールドを「クラス変数」と呼び、
static修飾子が付いていないメソッドを「インスタンスメソッド」、フィールドを「インスタンス変数」と呼ぶ

- まず使い所は、全インスタンス変数が使えるようなメンバ変数、メソッドを定義するにはStaticを使用する
- クラスを管理するような便利なメソッドをメソッドを使いたいばあいStaticを使用する

```実行クラス
class Student{
  String name;
ここで使う
  static int counter = 0;

  Student(String n){
    name = n;
    counter++;
    System.out.println(name + "さんをインスタンス化");
  }
  static void display(){
    System.out.println(counter + "人");
  }
}

```

```設計クラス
class StuSample{
  public static void main(String[] args){
    Student.display();

    Student stu1 = new Student("kouno");
    Student.display();

    Student stu2 = new Student("tanaka");
    Student.display();
  }
}

```


## そもそも「クラスメソッド」「クラス変数」「インスタンスメソッド」「インスタンス変数」の違いは？
### クラスメソッド (staticメソッド)
全員で使うメソッド。
オブジェクトを作らなくても使える。
キーワード：static を使って宣言する。
### クラス変数 (static変数)
全員で共有する変数。
クラス全体で1つだけ作られる。
キーワード：static を使って宣言する。
### インスタンスメソッド
1人1人が持つメソッド。
オブジェクトを作らないと使えない。
### インスタンス変数
1人1人が持つ変数。
オブジェクトごとに別々の値を持てる。
```
class School {
    // クラス変数 (全員で共有)
    static String schoolName = "ABC中学校";

    // インスタンス変数 (個人の情報)
    String studentName;
    int mathScore;

    // クラスメソッド (クラス全体の操作)
    static void printSchoolName() {
        System.out.println("学校名: " + schoolName);
    }

    // インスタンスメソッド (個人の操作)
    void printStudentInfo() {
        System.out.println("名前: " + studentName + ", 数学の点数: " + mathScore);
    }
}

public class Main {
    public static void main(String[] args) {
        // クラスメソッドの使用 (オブジェクトを作らずに使える)
        School.printSchoolName();

        // インスタンスを作成して個人情報をセット
        School student1 = new School();
        student1.studentName = "太郎";
        student1.mathScore = 85;

        School student2 = new School();
        student2.studentName = "花子";
        student2.mathScore = 90;

        // インスタンスメソッドの使用 (オブジェクトごとに別々の動作)
        student1.printStudentInfo();
        student2.printStudentInfo();
    }
}

```

使い分けのポイント
クラスメソッドやクラス変数 (static):

全員で共有するデータや動作に使う。
例: 学校名、全校生徒数を計算する関数など。
インスタンスメソッドやインスタンス変数:

個人ごとのデータや動作に使う。
例: 生徒の名前、成績、個人の行動など
