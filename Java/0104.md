### 「クラス」

設計図クラス（変数を使って属性を表したとこ、メソッドが記述されたとこ）、実行用クラス（mainメソッドが記述されたとこ）の２種類がある。
設計図を元に具体的なデータ（プロパティ）を入れたものをオブジェクトと呼ぶ。これらが複数合って、それらを実行用のクラスで呼び出すのがオブジェクト指向。

<details><summary>コード</summary>

  ```
  
  class Student{
    //メンバ変数（属性）
    String name;
    int engScore;
    int mathScore;
  
    メソッド（操作）
    void display(){
      System.out.println(name + "さん");
      System.out.println("英語" + engScore + "点・数学" + mathScore + "点");
    }
    void setScore(int eng, int math){
      engScore = eng;
      mathScore = math;
    }  
    double getAvg(){
      double avg = (engScore + mathScore) / 2.0;
      return avg;
    }
  }
  
```
  
</details>

## オブジェクトの使い方のイメージ
1 生成＝インスタンス化
` Student stu1 = new Student(); `
２　変数.メソッドを利用

```java
//オブジェクト.変数名
   stu1.name = "kono";
//オブジェクト.メソッド名(引数)
    stu1.setScore(90, 80);
```

## インスタンスとは
設計図クラス基に、具体的な値を当てはめて実体化したものをインスタンスと呼ぶ。
（例）
Aさん、英語５０点、数学１００点
Bさん、英語１００点、数学７０点
Cさん、英語１００点、数学１００点　

## オーバーロードとは
メソッドに与える引数の数、データ型、順番のどれかが異なっていれば、1つのクラス内で同じメソッド名を複数使用することができる、という機能
本来、１つのクラス内に同名のメソッドがあればコンパイルエラーとなる、
同じ名前を持つメソッドが複数あっても、それらに与える引数の数、データ型、順番のどれか1つが異なっていれば、エラーにならずコンパイルを行うことが可能。この機能がオーバーロード。
→つまりJavaでは、メソッド名だけではなく、引数の状態まで見てメソッドの識別を行なっているということ


## 「コンストラクタ」
`インスタンス生成時に呼び出される特別なメソッドで主にそのクラスのメンバ変数を初期化するときに使用する`
メンバ変数の初期化を行っておらず、また一度も値を格納しないままメンバ変数の値を表示しようとするとnullになる。
```
public class メインクラス名{
    public static void main(String[] args) {
    
        //インスタンスの生成
        クラス名 変数名 = new クラス名(コンストラクタへの引数);    
    }
}
 
class クラス名{
 
    //コンストラクタ（インスタンス生成時に実行される）
    public クラス名(){
        初期化処理など
    }
}
```

注意点は
戻り値は記載しない
メソッド名はクラス名と同じものにする
