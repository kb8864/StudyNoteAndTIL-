# オーバライドとオーバーロード

| 特徴	| オーバーライド | オーバーロード|
|:-----------------|:------------------|:-------------------|
目的	|親クラスのメソッドを上書き	|同名メソッドを引数違いで使い分ける|
|場所	|親クラスと子クラスで発生	|同じクラス内で発生|
|メソッド名	|親クラスと完全に同じ	|同じ名前で引数が異なるメソッド|
|引数の型や数	|親クラスと完全に一致	|異なるパターンで定義可能|
|アノテーション	|@Overrideを使う	|アノテーションは不要|

## 使い分け
オーバーライド
親クラスの基本機能を活かしつつ、子クラス独自の動作を追加・変更したい場合に使用。
親クラスと同じ名前、引数、戻り値の型でメソッドを作成し、処理内容を変更したい場合に使用。

オーバーロード
同じ目的の処理を、引数の違いによって柔軟に対応させたい場

## コード
オーバーライド
```
// 親クラス
public class Person2 {
    private String name;

    public void setName(String n) {
        name = n;
    }

    public String getName() {
        return name;
    }

    // 親クラスのdisplayメソッド
    public void display() {
        System.out.println("名前：" + name);
    }
}
```

```
// 子クラス
public class Student2 extends Person2 {
    private int stuNo;

    public void setStuNo(int s) {
        stuNo = s;
    }

    // オーバーライドされたdisplayメソッド
    @Override
    public void display() {
        System.out.println("名前：" + getName());
        System.out.println("学籍番号：" + stuNo);
    }
}
```
```
実行クラス
public class StuSample2 {
    public static void main(String[] args) {
        Student2 stu = new Student2();
        stu.setName("指名");  // 親クラスのメソッドを使用
        stu.setStuNo(12345);     // 子クラスのメソッドを使用
        stu.display();       // 子クラスでオーバーライドされたメソッドが呼び出される
    }
}
```

---

オーバーロード
```
// 親クラス
public class Person2 {
    private String name;

    public void setName(String n) {
        name = n;
    }

    public String getName() {
        return name;
    }

    public void display() {
        System.out.println("名前：" + name);
    }

    // 引数付きdisplayメソッド（オーバーロード）
    public void display(String prefix) {
        System.out.println(prefix + name);
    }
}
```
```
// 実行クラス
public class StuSample2 {
    public static void main(String[] args) {
        Person2 person = new Person2();
        person.setName("佐藤");

        // displayのオーバーロードメソッドを呼び出す
        person.display();              // 引数なしメソッド
        person.display("名前：");      // 引数付きメソッド
    }
}
```
