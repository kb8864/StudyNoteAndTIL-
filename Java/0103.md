# var型について
varを使う場合、必ず初期値を指定する必要がある。Javaは右側の値を見て型を決めるので、初期化しないと「型を決められない」とエラーになる。
```
var name; // コンパイルエラー: 初期化なしでは型を推測できない
var name = "Taro"; // 初期値があれば型が推測可能

var ary1 = {1,2,3} // コンパイルエラー: 初期化なしでは型を推測できない
var ary1 = new int[]{1, 2, 3}; // 配列リテラルを正しく記述

```

配列を作成する際、配列のサイズ（長さ）を指定するか、初期値を与える必要がある。要素数の指定がないとコンパイルエラーとなる
```
var ary4 = new int[];
var ary4 = new int[3];         // 長さ3の配列を作成
var ary4 = new int[]{1, 2, 3}; // 初期値を指定

```
Javaでは配列やオブジェクトを作成する場合、明示的な型が必要
newの後に{}のみ記述しているのでコンパイルエラー
```
var ary5 = new {1, 2, 3};
var ary5 = new int[]{1, 2, 3}; // 配列として初期化

```

# StringBuilderクラスについて
特に文字列を頻繁に変更する場合によく使う。
String はイミュータブル（不変）であるため、変更操作を行うたびに新しいインスタンスが作成されますが、
StringBuilder は変更可能で、同じオブジェクト内で操作が行われます。

実務での使用シーン
- CSVやHTMLなどの文字列を大量に生成する際に使うと効率的

 ```
StringBuilder csvBuilder = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    csvBuilder.append("Data").append(i).append(",");
}
System.out.println(csvBuilder.toString());
```

-  一時的な文字列操作でつかえる
