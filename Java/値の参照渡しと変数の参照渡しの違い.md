# 値の参照渡しと変数の参照渡しの違い

### **値の参照渡しと変数の参照渡しの違い**
値の参照渡しと変数の参照渡しの違いは、**「メモリのどの部分が渡され、変更がどこに影響を与えるか」** にあります。

---

## **1. 値の参照渡しと変数の参照渡しの違いを簡単にまとめる**
| **種類** | **メモリの渡し方** | **影響する範囲** |
|----------|----------------|----------------|
| **値の参照渡し** | **オブジェクトのアドレス（参照）をコピーして渡す** | **元のオブジェクト自体が変更される** |
| **変数の参照渡し** | **変数のアドレスをコピーして渡す** | **渡した変数そのものを別のオブジェクトに変更できる** |

---

## **2. 値の参照渡し（参照型の値を渡す）**
### **コード例**
```java
class Sample {
    int num;
    
    Sample(int num) {
        this.num = num;
    }
}

public class Main {
    public static void changeValue(Sample obj) {
        obj.num = 100; // objが参照しているオブジェクトのnumを変更
    }

    public static void main(String[] args) {
        Sample s = new Sample(10);
        System.out.println("変更前: " + s.num); // 10

        changeValue(s);

        System.out.println("変更後: " + s.num); // 100
    }
}
```

### **結果**
```
変更前: 10
変更後: 100
```

### **解説**
- `Sample` クラスのオブジェクト `s` は `num = 10` を持つ。
- `changeValue(s)` により、**オブジェクトの参照（アドレス）が渡される**。
- `obj.num = 100;` で **元の `s` が参照しているオブジェクトの `num` を変更**。
- そのため、`s.num` も `100` に変わる。

✔ **「値の参照渡し」では、オブジェクトの中身が変更される！**  
✔ **しかし `s` という変数自体は `changeValue` の中で変更されていない！**  

---

## **3. 変数の参照渡し（変数自体を変更）**
### **コード例**
```java
class Sample {
    int num;
    
    Sample(int num) {
        this.num = num;
    }
}

public class Main {
    public static void changeReference(Sample obj) {
        obj = new Sample(100); // objを新しいオブジェクトに変更
    }

    public static void main(String[] args) {
        Sample s = new Sample(10);
        System.out.println("変更前: " + s.num); // 10

        changeReference(s);

        System.out.println("変更後: " + s.num); // 10 （変わらない）
    }
}
```

### **結果**
```
変更前: 10
変更後: 10
```

### **解説**
- `Sample` クラスのオブジェクト `s` は `num = 10` を持つ。
- `changeReference(s)` により、**変数 `s` の参照（アドレス）が `obj` にコピーされる**。
- **`obj = new Sample(100);` で `obj` は新しいオブジェクトを指すが、これは `s` には影響しない！**
- `s` は元のオブジェクトのままなので、`num` は `10` のまま。

✔ **「変数の参照渡し」では、メソッド内の変数の参照は変えられても、元の変数は影響を受けない！**  
✔ **新しいオブジェクトを作っても、元の変数が参照しているオブジェクトとは関係ない！**  

---

## **4. 両者の違いを図で説明**
### **値の参照渡し**
```
[Main]                      [Heap]
s ---------------> (num: 10)  

changeValue(s) を実行すると:
s ---------------> (num: 100)  ← 元のオブジェクトの中身を変更
```
**✔ 参照は変わらず、オブジェクトの中身だけが変わる。**

---

### **変数の参照渡し**
```
[Main]                      [Heap]
s ---------------> (num: 10)  

changeReference(s) を実行すると:
obj ---------------> (num: 100)  ← ここで新しいオブジェクトを作る
s ---------------> (num: 10)     ← しかしsは元のオブジェクトを参照したまま
```
**✔ `obj` の参照は変わるが、`s` には影響がない。**

---

## **5. まとめ**
| **比較** | **値の参照渡し** | **変数の参照渡し** |
|----------|----------------|----------------|
| **渡すもの** | **オブジェクトのアドレス（参照）** | **変数のアドレス（参照）** |
| **影響するもの** | **元のオブジェクトの中身が変わる** | **元の変数には影響しない** |
| **オブジェクトの参照先** | **変わらない** | **変えられるが、元の変数には影響なし** |
| **変更の影響範囲** | **元のオブジェクトに影響する** | **元の変数には影響しない** |

✔ **オブジェクトの中身を変更するなら「値の参照渡し」**  
✔ **変数自体を別のオブジェクトに変更するなら「変数の参照渡し」**  

---

## **6. 簡単な理解のポイント**
1. **値の参照渡し**
   - **「メモ帳を渡す」イメージ**
   - 渡された人がメモの内容を書き換えると、元のメモ帳の内容が変わる。

2. **変数の参照渡し**
   - **「メモ帳を指すポインタを渡す」イメージ**
   - 渡された人が **ポインタを別のメモ帳に向けても、元のポインタの参照先は変わらない。**
