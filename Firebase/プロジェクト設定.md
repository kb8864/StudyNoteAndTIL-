## 1. 「プロジェクト設定」はどこにある？

添付していただいた画像の**左側メニュー**にあります。

1.  左メニュー上部にある**「設定（歯車アイコン）」**をクリックします。
2.  表示されたメニューの中から**「プロジェクトの設定」**を選択してください。


### Webアプリの追加手順
プロジェクト設定画面を開いたら、以下の手順で進めます。

1.  **「全般」**タブが表示されていることを確認します。
2.  下の方にある「マイアプリ」セクションの**「Web」アイコン（ `</>` ）**をクリックします。
3.  アプリのニックネームを入力して「アプリを登録」をクリックします。
4.  すると、`const firebaseConfig = { ... };` というコードが表示されます。これが「設定値」です。

## 2. 「設定値」は何のために、どこで使うのか？

コピーした設定値（`apiKey` や `authDomain` などが含まれるオブジェクト）は、**「あなたのウェブサイトと、Firebaseのサーバーを紐付けるための鍵」**として機能します。

### なぜ必要なのか？
Firebaseは世界中で多くの人が利用しています。設定値がないと、プログラムを動かした際に「どのプロジェクトのデータベース（Firestore）にデータを保存すればいいのか」を判別できません。この設定値があることで、プログラムが迷わずあなたのプロジェクトにアクセスできるようになります。

### どこで使うのか？
通常、フロントエンド（ブラウザ側）のソースコード内で使用します。

* **ファイル名例:** `src/firebase.js` や `firebaseConfig.js` など
* **具体例:** 以下のように、Firebase SDKを初期化する際に書き込みます。

```javascript
// Firebase SDKから必要な機能をインポート
import { initializeApp } from "firebase/app";
import { getFirestore } from "firebase/firestore";

// ここにコピーした「設定値」を貼り付ける
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project",
  // ... その他の値
};

// Firebaseの初期化
const app = initializeApp(firebaseConfig);

// これでFirestoreが使えるようになる
export const db = getFirestore(app);
```

> [!NOTE]
> 手順4で作成する「サービスアカウント（JSONファイル）」は**サーバー側（Node.jsなど）**で強力な権限として使いますが、この「Webアプリの設定値」は**ブラウザ側**で一般的に公開される形で使われるものです。役割が異なるので注意しましょう。
