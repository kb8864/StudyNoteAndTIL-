# インターフェース
- 定数と抽象メソッドの定義（宣言）のみを持つ型で、実装を持ちません（デフォルトメソッドを除く）。
- インターフェースを実装（implements）したクラスは、implementsキーワードで指定したすべてのメソッドをオーバーライドする必要がある。オーバライドする際は、実装クラスは必ずpublicをつける必要がある
-  クラスは複数のインターフェースを実装可能
-  継承関係がないクラスに共通のメソッドを持たせたい場合に使う
-  インターフェースで宣できる変数はstaticな変数のみ。宣言してないと強制的にpublic static final修飾子がつく。



## 継承関係がないクラスに共通のメソッドを持たせたい場合に使う

そもそもなぜインターフェースが必要なのか？
継承を使う場合、クラス間に**IS-A（〜は〜の一種である）**という明確な関係が必要。しかし次のような状況では継承が適さない場合がある
1異なる種類のクラスに共通の動作を追加したい

例: 鳥（Bird）と飛行機（Airplane）は、継承関係はないが、どちらも「飛ぶ」という動作を持つ。
解決: 両方にFlyableインターフェースを実装させる。

2　既存の継承関係を壊したくない

Javaでは多重継承ができないため、親クラスを変更せずに共通の動作を追加する必要がある場合にインターフェースが役立つ。


BirdとAirplaneは継承関係がないが、Flyableインターフェースを実装することで、「飛ぶ」という共通の振る舞いを持たせるようにしたコード。


```
// 飛ぶ動作を定義するインターフェース
public interface Flyable {
    void fly();
}

// 鳥クラス
public class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("鳥が空を飛びます！");
    }
}

// 飛行機クラス
public class Airplane implements Flyable {
    @Override
    public void fly() {
        System.out.println("飛行機が空を飛びます！");
    }
}

// メインクラス
public class Main {
    public static void main(String[] args) {
        Flyable bird = new Bird();
        Flyable airplane = new Airplane();

        bird.fly();       // 鳥が空を飛びます！
        airplane.fly();   // 飛行機が空を飛びます！
    }
}
インターフェースを使うと異なる種類のクラスでも共通の動作を統一的に扱うことが可能
```

# インターフェースと継承の違い

|項目	|インターフェース|	継承（親クラス）|
|目的	|異なるクラス間で共通の振る舞いを持たせたい場合、振る舞い（メソッド）を定義する	|特定の機能やデータを子クラスに引き継ぐ,IS-Aの関係が成り立つ|
|キーワード	|interface	|extends|
|多重利用	|クラスは複数のインターフェースを実装できる|	クラスは1つの親クラスしか継承できない|
|実装の有無	|メソッドは通常、中身を持たず宣言のみ（Java 8以降、defaultメソッドあり）	|メソッドは中身を持つ（具体的な実装がある）|
|フィールドの扱い|	定数のみ（暗黙的にpublic static final）	|通常のインスタンス変数やメソッドを持つ|
|使用目的|	異なるクラス間で共通の振る舞いを共有	|親クラスの性質を引き継ぎつつ拡張|


継承は「特定の性質を持つクラスをさらに具体化する」ために使う。
```
// 親クラス
class Animal {
    void eat() {
        System.out.println("This animal eats food.");
    }
}

// 子クラス
class Dog extends Animal {
    void bark() {
        System.out.println("The dog barks.");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.eat();  // 親クラスのメソッドを使う
        dog.bark(); // 子クラス独自のメソッド
    }
}

DogはAnimalを継承しており、eat()メソッドをそのまま使える。
Dog独自のbark()メソッドも追加されている。
```



インターフェースは「異なるクラス間で共通の振る舞いを保証する」ために使う。
```
// インターフェース
interface Flyable {
    void fly();
}

// クラス1
class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("The bird flies.");
    }
}

// クラス2
class Airplane implements Flyable {
    @Override
    public void fly() {
        System.out.println("The airplane flies.");
    }
}

public class Main {
    public static void main(String[] args) {
        Flyable bird = new Bird();
        Flyable airplane = new Airplane();

        bird.fly();       // The bird flies.
        airplane.fly();   // The airplane flies.
    }
}
BirdとAirplaneはどちらもFlyableを実装しており、fly()メソッドを必ず持つ。
Flyableを使うことで、「飛ぶ」という振る舞いが保証されている。
```

## 比較場面
継承を使う場面
IS-Aの関係が成り立つ場合:
例: 犬（Dog）は動物（Animal）の一種である。
親クラスの機能やデータをそのまま使いたい場合。
インターフェースを使う場面
異なるクラス間で共通の振る舞いを持たせたい場合:
例: 飛ぶ動作（Flyable）や泳ぐ動作（Swimable）など。
多重継承が必要な場合:
Javaではクラスの多重継承はできないが、インターフェースは複数実装可能。

# インターフェースと継承の併用
 親クラスとインターフェースを組み合わせる
 必ず、extends を先に書いてimplementsを後にかく

 ```
package projava;
// インターフェース
public interface ExtendsImplements {
    void methodA();
}
//　親クラス
class Super{
    void methodA();
}
class MyClass extends Super implements ExtendsImplements{
    public void methodA() { }
}
```
